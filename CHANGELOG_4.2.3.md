# Changelog — Matara University ERP 4.2.3

- Added shared ERP-backed LMS APIs for student and lecturer dashboards.
- Added scoped assignment creation, submission review, text submission/resubmission, marking and explicit feedback release.
- Added submission history snapshots for resubmissions and marking changes.
- Added dedicated student and lecturer assignment pages and routes.
- Tightened legacy assessment unit access and removed whole-school fallback from empty assessment rosters.
- Restricted supplementary decisions to examination-office roles.
- Updated package and health-check version metadata.
- Full build/test verification remains blocked by missing installed dependencies; see `ERP_AUDIT_AND_REPAIR_4.2.3.md`.
